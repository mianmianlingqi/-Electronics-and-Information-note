## 第1章 逻辑代数基础

### 📖 名词解释

- **模拟量**：时间、数值均连续
- **数字量**：时间、数值均离散（采样→量化→编码）
- **逻辑函数**：n 个输入 → 2ⁿ 行真值表

### 🔴 数制转换口诀

| 转换 | 方法 |
|---|---|
| 十 → 二 | 整数：**除 2 取余**，余数逆序 |
| 二 → 八 | 三位一组，不足补 0 |
| 二 → 十六 | 四位一组，不足补 0 |
| 十 ↔ 8421 BCD | 每位十进制 → 4 位二进制 |

### 8421 BCD 注意

- 位权：8、4、2、1
- **≠ 普通二进制**（如十进制 6：BCD 是 0110，不是 110）

### 格雷码

**相邻两位仅差 1 位**（抗干扰）

### 🔴 基本逻辑

| 运算 | 口诀 | 表达式 |
|---|---|---|
| 与 | 全 1 才 1 | F = AB |
| 或 | 有 1 则 1 | F = A + B |
| 非 | 0/1 互换 | F = Ā |
| 异或 | 不同为 1 | F = A⊕B = ĀB + A B̄ |
| 同或 | 相同为 1 | F = A⊙B = Ā B̄ + AB |

### 📐 基本公式（会默写）

$$A + 0 = A, \quad A + 1 = 1, \quad A + A = A$$

$$A \cdot 0 = 0, \quad A \cdot 1 = A, \quad A \cdot A = A$$

$$A + \overline{A} = 1, \quad A \cdot \overline{A} = 0$$

$$A + AB = A, \quad A(A+B) = A$$

### 🔴 摩根定律（必背）

$$\overline{A + B} = \overline{A} \cdot \overline{B}$$

$$\overline{A \cdot B} = \overline{A} + \overline{B}$$

### 反演规则 vs 对偶规则

| 规则 | 操作 |
|---|---|
| **反演** | 运算互换 + 0/1 互换 + **变量取反** → 得 F̄ |
| **对偶** | 运算互换 + 0/1 互换 + **变量不变** → 得 F′ |

优先顺序：**括号 > 与 > 或 > 非**

### 最小项

- n 变量 → **2ⁿ 个**最小项
- 每个最小项包含**全部 n 个变量**（原或反各出现一次）

### 卡诺图化简口诀

**圈大圈少，1 的 2ⁿ 格**

- 相邻格只有 1 位不同
- 无关项 d 可当 0 或 1 用，使圈更大

## 第3章 组合逻辑

### 📖 名词解释

- **组合逻辑**：无记忆，输出**只取决于当前输入**
- **时序逻辑**：有记忆，输出与**过去输入/状态**有关
- **编码**：用二进制表示信号（编码器）
- **译码**：二进制 → 特定输出（译码器）
- **竞争-冒险**：信号变化瞬间可能产生错误尖峰

### 🔴 分析四步（背）

逻辑图 → 写表达式 → 化简 → 真值表 → **功能描述**

### 🔴 设计五步（大题高频）

1. 逻辑抽象（定义输入输出）
2. 列真值表
3. 写表达式 / 画卡诺图
4. 化简
5. 画逻辑图

### 常用器件

| 器件 | 要点 |
|---|---|
| 编码器 | n 个信号 → log₂n 位代码 |
| 优先编码器 | 同时多个有效 → 编**优先级最高** |
| 74LS138 | 3 线-8 线译码，Y0～Y7 = **全部最小项** |
| 74LS151 | 8 选 1 数据选择器 |
| 74LS47 / 48 | 47 配**共阳极**，48 配**共阴极** |
| 全加器 | 考虑低位进位 |

### MUX 实现逻辑函数

K 个变量，n 个选择端 → 三种情况（选通端不足/相等/有余）

步骤：表达式 → 最小项 → 接数据端 / 变量接选择端

### 消除冒险

加封锁脉冲、选通脉冲、滤波电容、**修改逻辑设计**

## 第4章 触发器

### 📖 名词解释

- **触发器**：存 1 位二进制，有两个稳态 0/1
- **空翻**：一个 CP 周期内多次翻转
- **边沿触发**：仅上升沿或下降沿有效

### CP 端圆圈

- **无圈** → 上升沿触发
- **有圈** → 下降沿触发

### 🔴 特性方程（必须默写）

**D 触发器**：

$$Q^{n+1} = D$$

**JK 触发器**：

$$Q^{n+1} = J\overline{Q^n} + \overline{K}Q^n$$

**T 触发器**：

$$Q^{n+1} = T\overline{Q^n} + \overline{T}Q^n$$

**SR 触发器**：约束 **SR = 0**（不能同时为 1）

### 基本 RS（或非门）

| S | R | Q |
|---|---|---|
| 0 | 1 | 置 0 |
| 1 | 0 | 置 1 |
| 0 | 0 | 保持 |

### 同步 vs 基本 RS

- **基本 RS**：任何时候都响应
- **同步 RS**：仅 **CP = 1** 时响应

## 第5章 时序逻辑

### 🔴 分析步骤（大题高频，背）

1. 写**驱动方程**（各触发器输入）
2. 代入特性方程 → **状态方程**
3. 列状态表 / 画状态图
4. 画时序图
5. 判断功能

### 寄存器

- 1 个触发器存 1 位 → n 位寄存器要 n 个 FF

### 计数器

- **模 M**：一个循环包含 M 个状态
- **自启动**：偏离有效序列后能回到有效循环（**考试常查**）

### 🔴 74LS161（2023 真题）

- 四位二进制**同步**加法计数器
- 构成 M 进制：**清零法** / **置数法**

## 第6章 ADC / DAC

### 📖 名词解释

- **DAC**：数字 → 模拟
- **ADC**：模拟 → 数字
- **分辨率**：n 位 → 最多 2ⁿ 个输出等级

### ADC 四步

**采样 → 保持 → 量化 → 编码**

### 🔴 采样定理（必背）

$$f_s \geq 2 f_{max}$$

采样频率 ≥ 2 倍最高频率分量
