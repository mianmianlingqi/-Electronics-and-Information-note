# 电路分析 · 背诵速记

> 第1～6章核心考点，按「口诀 → 公式 → 步骤 → 易混」排列。

## 第1章 基本概念与定律

### 🔴 必背填空

- 电路三要素：**电源、负载、中间环节**
- 五种理想元件：R、L、C、**电压源、电流源**
- 1度电 = 1 kWh = **3.6 MJ**（2023填空）
- 电导 G = 1/R，单位 **西门子 S**

### 📖 名词解释（原句背）

- **关联参考方向**：u、i 参考方向一致；不一致为非关联
- **KCL**：任一节点，各支路电流代数和 = 0
- **KVL**：任一回路，各支路电压代数和 = 0

### 📐 公式墙

$$V_{ab} = V_a - V_b, \qquad V_{ab} = -V_{ba}$$

关联方向：p = ui；非关联：p = −ui

P > 0 → 吸收功率（负载）；P < 0 → 发出功率（电源）

$$u = Ri \quad (\text{关联})$$

### 口诀

| 内容 | 口诀 |
|---|---|
| 电流/电压参考 | 同向为正，反向为负 |
| 负载参考方向 | 负载全是关联方向 |
| 电位 | V高 − V低 = 元件电压 |
| 源的判断 | 算 P：正吸负发 |

### 🔴 独立源规则

| 类型 | 口诀 |
|---|---|
| 恒压源 | **并联看电压，串联看电流** |
| 恒压源 | 不同恒压源**不能直接并联** |
| 恒压源串联 | 同向加、反向减 |
| 恒流源 | 不同恒流源**不能串联** |
| 恒流源并联 | 同向正、反向负 |
| 恒流源支路 | 串联恒流源的那支路电流 = Is |
| 实际电源 | 恒压串 R ⇄ 恒流并 R（**对外等效**） |
| 受控源 | **戴维南等效时不可去掉控制量** |

## 第2章 等效变换

### 📐 公式墙

串联：

$$R_{eq} = R_1 + R_2 + \cdots$$

并联：

$$\frac{1}{R_{eq}} = \frac{1}{R_1} + \frac{1}{R_2} + \cdots$$

两电阻并联分流（必考）：

$$i_1 = \frac{R_2}{R_1 + R_2} i, \qquad i_2 = \frac{R_1}{R_1 + R_2} i$$

### 口诀

- **串联分压，并联分流**
- **对外等效，对内不等效**

### △ ↔ Y 变换（必须会背）

△ → Y：

$$R_1 = \frac{R_{12}R_{31}}{R_{12}+R_{23}+R_{31}}, \quad R_2 = \frac{R_{12}R_{23}}{R_{12}+R_{23}+R_{31}}, \quad R_3 = \frac{R_{23}R_{31}}{R_{12}+R_{23}+R_{31}}$$

Y → △：分子变分母，分母变分子（对称轮换）

## 第4章 电路定理

### 📖 名词解释

**叠加定理**：线性电路中，任一支路响应 = 各独立源单独作用时响应的**代数和**。

**齐次定理**：所有激励同乘 K，响应也乘 K。

**替代定理**：已知某支路 Uk、Ik，可用 Uk 的恒压源或 Ik 的恒流源替代，其余不变。

**戴维南定理**：有源一端口 ⇄ **Uoc 串 Req**（Req = 独立源置零后的等效电阻）。

**诺顿定理**：有源一端口 ⇄ **Isc 并 Req**。

### 🔴 叠加定理四忌

1. 只适用于**线性**电路
2. **功率不能叠加**
3. 注意各分量参考方向
4. 受控源**保留**，独立源置零（压短流开）

### 📐 最大功率传输

$$R_L = R_{eq} \text{ 时功率最大}$$

$$P_{max} = \frac{U_{oc}^2}{4R_{eq}} = \frac{1}{4}R_{eq} I_{sc}^2$$

### 戴维南/诺顿步骤（背）

1. 求 **Uoc**（开路电压）或 **Isc**（短路电流）
2. 独立源置零 → 求 **Req**
3. 画等效电路 → 接负载求解

## 第5章 暂态分析

### 🔴 换路定则（必背）

$$i_L(0_+) = i_L(0_-), \qquad u_C(0_+) = u_C(0_-)$$

只有 **iL 和 uC** 不能突变！

### 稳态化简口诀

| 状态 | 电感 L | 电容 C |
|---|---|---|
| 直流稳态 | **短路**（导线） | **开路**（断路） |
| 暂态过程 | 不能突变 | 不能突变 |

### L/C 串并联类比

| 操作 | 等效于电阻 |
|---|---|
| 电容串联 | 电阻**并联** |
| 电容并联 | 电阻**串联** |
| 电感串联 | 电阻**串联** |
| 电感并联 | 电阻**并联** |

### 📐 时间常数

$$\tau_{RC} = R_{eq} C, \qquad \tau_{RL} = \frac{L}{R_{eq}}$$

Req：从 L 或 C 端子看进去的戴维南电阻（**换路后**电路）

### 🔴 三要素法（大题必考，整段背）

$$f(t) = f(\infty) + \big[f(0_+) - f(\infty)\big] e^{-t/\tau}$$

适用于 **一阶电路**任意 u 或 i。

### 三要素五步（背步骤号）

1. **t = 0−**：稳态 → 求 uC(0−)、iL(0−)
2. **换路定律** → 得 0+ 初值
3. **t > 0 电路** → 求 τ
4. **t → ∞** 新稳态 → 求 f(∞)
5. 代入公式；需要时用：

$$i_C = C\frac{du_C}{dt}, \qquad u_L = L\frac{di_L}{dt}$$

### 响应类型

| 名称 | 条件 |
|---|---|
| 零输入 | 无激励，靠初始储能 |
| 零状态 | 初始为零，靠激励 |
| 全响应 | 初始 ≠ 0 且有激励 |

## 第6章 交流电路

### 🔴 正弦三要素

$$i(t) = I_m \cos(\omega t + \psi)$$

幅值 Im、角频率 ω、初相 ψ

$$U = \frac{U_m}{\sqrt{2}}, \qquad \omega = 2\pi f$$

### 相量对应（必背）

$$i(t) = \sqrt{2} I \cos(\omega t + \Psi) \quad \Longleftrightarrow \quad \dot{I} = I \angle \Psi$$

### sin / cos 统一

$$\cos\theta = \sin(\theta + 90^\circ)$$

只有 **ω 相同** 才能比相位差。

### 🔴 元件口诀

**感压容流** —— L：电压超前电流 90°；C：电流超前电压 90°

乘 **j** → 逆时针 90°（超前）；乘 **1/j** → 顺时针 90°（滞后）

### 📐 阻抗 / 导纳

$$Z_R = R, \qquad Z_L = j\omega L, \qquad Z_C = -j\frac{1}{\omega C}$$

$$X_L = \omega L, \qquad X_C = \frac{1}{\omega C}$$

RLC 串联：

$$Z = R + j(X_L - X_C)$$

RLC 并联（用导纳）：

$$Y = G + j\left(\omega C - \frac{1}{\omega L}\right)$$

Z ↔ Y 互化（必背）：

$$Y = \frac{R - jX}{R^2 + X^2} = G + jB$$

$$Z = \frac{G - jB}{G^2 + B^2} = R + jX$$

两阻抗并联：

$$Z = \frac{Z_1 Z_2}{Z_1 + Z_2}$$

### 📐 功率

$$P = UI\cos\varphi \quad (\text{W})$$

$$Q = UI\sin\varphi \quad (\text{var})$$

$$S = UI = \sqrt{P^2 + Q^2} \quad (\text{VA})$$

| 元件 | P | Q |
|---|---|---|
| R | UI | 0 |
| L | 0 | +UI |
| C | 0 | −UI |

X > 0 → 感性；X < 0 → 容性

### 🔴 谐振

**串联谐振条件**：XL = XC

$$\omega_0 = \frac{1}{\sqrt{LC}}, \qquad f_0 = \frac{1}{2\pi\sqrt{LC}}$$

| 特征 | 串联谐振 |
|---|---|
| 阻抗 | **最小** = R |
| 电流 | **最大** |
| 相位 | u、i **同相** |
| UL 与 UC | 大小相等、相位相反 |

$$Q = \frac{1}{R}\sqrt{\frac{L}{C}}$$

**并联谐振**：XL = XC，导纳最小、总电流最小

### 实际线圈

直流求 R；交流求 Z：

$$|Z| = \sqrt{R^2 + X_L^2}, \qquad X_L = \sqrt{Z^2 - R^2}, \qquad L = \frac{X_L}{\omega}$$

## 易混对比卡

| A | B |
|---|---|
| 电压源置零 | 短路 |
| 电流源置零 | 开路 |
| 电感稳态 | 短路 |
| 电容稳态 | 开路 |
| 串联谐振 | 阻抗最小、电流最大 |
| 并联谐振 | 导纳最小、电流最小 |
| 相量用 | **有效值**，不是峰值 |
| 交流写 i、u | 小写；直流稳态 | 大写 |

## 大题流程速记

**支路电流法**：标方向 → KCL + KVL → 解方程

**戴维南**：Uoc → Req → 等效 → 接负载

**三要素**：0− → 换路 → τ → ∞ → 公式

**交流并联**：U 相同 → 各支路 I = U/Z → 相量相加
