## 一、正弦量的三种表示

| 形式 | 例子 | 用途 |
|:---:|:---:|---|
| 瞬时值 | $u = U_m\sin(\omega t + \varphi)$ | 写波形、求某时刻值 |
| 相量（有效值） | $\dot{U} = U\angle\varphi$ | 计算、画相量图 |
| 复数 | $\dot{U} = U e^{j\varphi}$ | 代数运算 |

> [!IMPORTANT]
> **换算关系**
> - 峰值 ↔ 有效值：$U_m = \sqrt{2}\,U$
> - 相量用**有效值**，不是峰值
> - $\sin$ 与 $\cos$ 差 $90°$：$\cos\theta = \sin(\theta + 90°)$

## 二、R、L、C 的阻抗与相位

| 元件 | 阻抗 $Z$ | 电压相对电流 |
|:---:|:---:|:---:|
| R | $R$ | 同相（$\varphi = 0°$） |
| L | $j\omega L = jX_L$ | 电压超前电流 $90°$ |
| C | $\dfrac{1}{j\omega C} = -jX_C$ | 电压滞后电流 $90°$（电流超前电压 $90°$） |

### 2.1 判断元件类型

看 $\dot{U}$ 与 $\dot{I}$ 的相位差 $\varphi_Z = \varphi_U - \varphi_I$：

| $\varphi_Z$ | 元件 |
|:---:|:---:|
| $0°$ | 电阻 |
| $+90°$ | 电感 |
| $-90°$ | 电容 |

### 2.2 相量图记忆

```
        ↑ Im
        │   ·I_L（电感：I 滞后 U，U 超前）
        │
  ──────┼──────→ Re
        │   ·I_C（电容：I 超前 U）
        │
```

## 三、基本公式

| 名称 | 公式 |
|---|---|
| 欧姆定律（相量） | $\dot{U} = \dot{I} \cdot \dot{Z}$ |
| 并联 KCL | $\dot{I} = \dot{I}_1 + \dot{I}_2 + \cdots$ |
| 无功功率 | $Q = UI\sin\varphi$（电容 $Q<0$，电感 $Q>0$） |
| 电容储能 | $W_C = \dfrac{1}{2}CU^2$（$U$ 取有效值） |
| 角频率 | $\omega = 2\pi f$ |

> [!TIP]
> 复数运算：加减用直角坐标，乘除用极坐标（幅值相乘、角度相加）。

## 例题 2～8 详解

### 例题 2：相量加减乘 → 极坐标

**已知：** $\dot{A}_1 = 2\sqrt{3} + j2$，$\dot{A}_2 = 2 + j2\sqrt{3}$

**加法：**

$$\dot{A}_3 = \dot{A}_1 + \dot{A}_2 = (2\sqrt{3}+2) + j(2+2\sqrt{3}) = 2(\sqrt{3}+1)(1+j)$$

实部 = 虚部 → 幅角 $45°$

$$|\dot{A}_3| = 2(\sqrt{3}+1)\sqrt{2} = 2\sqrt{2}(\sqrt{3}+1)$$

$$\boxed{\dot{A}_3 = 2\sqrt{2}(\sqrt{3}+1)\,\angle 45°}$$

**乘法：**

$$\dot{A}_4 = (2\sqrt{3}+j2)(2+j2\sqrt{3}) = 4\sqrt{3} + j12 + j4 - 4\sqrt{3} = j16$$

$$\boxed{\dot{A}_4 = 16\angle 90°}$$

### 例题 3：两个正弦电流相加

**已知：**

- $i_1 = 2\sin(314t + 30°)$ A
- $i_2 = 5\cos(314t + 45°)$ A

**第一步：统一成 $\sin$ 形式**

$$i_2 = 5\cos(314t+45°) = 5\sin(314t+135°)$$

**第二步：写相量（有效值）**

$$\dot{I}_1 = \sqrt{2}\angle 30° \text{ A}, \qquad \dot{I}_2 = \frac{5}{\sqrt{2}}\angle 135° \text{ A}$$

**第三步：相量相加**

两相量夹角 $105°$，用平行四边形法则或分量法：

$$|\dot{I}| \approx 3.45 \text{ A}, \qquad \varphi_I \approx 93.6°$$

$$\boxed{i \approx 4.88\sin(314t + 93.6°)\ \text{A}}$$

> [!NOTE]
> 画相量图：$\dot{I}_1$ 在 $30°$，$\dot{I}_2$ 在 $135°$，对角线即 $\dot{I}$。

### 例题 4：判断元件类型并求参数

**已知：** $\dot{U} = 220\angle 120°$ V，$\dot{I} = 5\angle 30°$ A，$f = 50$ Hz

**相位差：**

$$\varphi_Z = 120° - 30° = 90° \quad \text{（电压超前电流）} \Rightarrow \textbf{纯电感}$$

**参数：**

$$Z = \frac{220}{5} = 44\ \Omega, \qquad L = \frac{X_L}{\omega} = \frac{44}{100\pi} \approx \boxed{140\ \text{mH}}$$

---

### 例题 5：电容 $i$、$Q$、$W_C$、相量图

**已知：** $C = 10\,\mu\text{F}$，$u = 220\sqrt{2}\sin(314t + 60°)$ V

**有效值：** $U = 220$ V，$\omega = 314$ rad/s

**容抗：**

$$X_C = \frac{1}{\omega C} = \frac{1}{314 \times 10 \times 10^{-6}} \approx 318.5\ \Omega$$

**电流（电容：电流超前电压 $90°$）：**

$$I = \frac{U}{X_C} = \frac{220}{318.5} \approx 0.691\ \text{A}$$

$$\boxed{i = 0.977\sin(314t + 150°)\ \text{A}}$$

**无功功率：**

$$Q = -UI \approx \boxed{-152\ \text{var}}$$

**平均储能：**

$$W_C = \frac{1}{2}CU^2 \approx \boxed{0.242\ \text{J}}$$

**相量图：** $\dot{U}$ 在 $60°$，$\dot{I}$ 在 $150°$（超前 $90°$）。

---

### 例题 6：线圈 $R$、$L$（直流 vs 交流）

**直流（只有电阻）：**

$$R = \frac{120}{20} = \boxed{6\ \Omega}$$

**交流：** $U = 220$ V，$I = 22$ A，$f = 50$ Hz

$$|Z| = \frac{220}{22} = 10\ \Omega$$

$$X_L = \sqrt{Z^2 - R^2} = \sqrt{100 - 36} = 8\ \Omega$$

$$L = \frac{8}{100\pi} \approx \boxed{25.5\ \text{mH}}$$

> [!TIP]
> 直流只测 $R$；交流测的是 $Z = \sqrt{R^2 + X_L^2}$。这是**实际线圈模型**：$R$ 与 $L$ 串联。

### 例题 7：并联电路（图 3.8）

**已知：** $I_1 = 5$ A，$I_2 = 5\sqrt{2}$ A，$U = 220$ V，$R = X_L$

**相量关系：**

- 支路 1（纯电容）：$\dot{I}_1$ 超前 $\dot{U}$ $90°$
- 支路 2（$R$ 与 $X_L$ 串联，$R = X_L$）：$\dot{I}_2$ 滞后 $\dot{U}$ $45°$

**求参数：**

$$X_C = \frac{U}{I_1} = \frac{220}{5} = \boxed{44\ \Omega}$$

$$|Z_2| = \frac{U}{I_2} = \frac{220}{5\sqrt{2}} = 22\sqrt{2}\ \Omega$$

$$R = X_L = \frac{|Z_2|}{\sqrt{2}} = \boxed{22\ \Omega}$$

**总电流（相量相加）：**

$\dot{I}_2$ 滞后 $45°$ → 水平分量 $5$ A，竖直分量 $-5$ A；加上 $\dot{I}_1$ 竖直 $5$ A：

$$\boxed{I = 5\ \text{A}} \quad \text{（与电压同相，纯电阻性）}$$

### 例题 8：两并联支路（图 3.9）

**已知：** $R_1 = R_2 = 10\ \Omega$，$L = 31.8$ mH，$C = 318\ \mu\text{F}$，$f = 50$ Hz，$U = 220$ V

**先算阻抗：**

$$\omega = 100\pi \approx 314\ \text{rad/s}$$

$$X_L = \omega L = 314 \times 0.0318 = 10\ \Omega$$

$$X_C = \frac{1}{\omega C} = \frac{1}{314 \times 318 \times 10^{-6}} \approx 10\ \Omega$$

→ $X_L = X_C$，结构对称。

**支路阻抗：**

$$Z_1 = 10 + j10 = 10\sqrt{2}\angle 45°\ \Omega$$

$$Z_2 = 10 - j10 = 10\sqrt{2}\angle -45°\ \Omega$$

**支路电流：**

$$I_1 = I_2 = \frac{220}{10\sqrt{2}} = 11\sqrt{2} \approx 15.6\ \text{A}$$

$$\varphi_{I1} = -45°, \qquad \varphi_{I2} = +45°$$

**总电流：**

两电流大小相等、相位差 $90°$：

$$\boxed{I = 22\ \text{A}, \quad \varphi_I = 0°}$$

**电容电压：**

$$\dot{U}_C = \dot{I}_2 \cdot (-jX_C) = 110\sqrt{2}\angle -45°\ \text{V}$$

$$\boxed{U_C \approx 155.6\ \text{V}}$$

| 量 | 结果 |
|---|---|
| $I_1$ | $15.6\angle -45°$ A |
| $I_2$ | $15.6\angle +45°$ A |
| $I$ | $22\angle 0°$ A |
| $U_C$ | $155.6\angle -45°$ V |
