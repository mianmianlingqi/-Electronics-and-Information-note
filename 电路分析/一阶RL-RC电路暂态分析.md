# 一阶 RL / RC 电路暂态分析

适用题型：电路中含一个储能元件（电感或电容），在 t=0 发生换路（开关动作），求初始值、时间常数或全响应。

## 一、换路定则（最基础，必背）

- 电感电流不能突变：`i_L(0+) = i_L(0-)`
- 电容电压不能突变：`u_C(0+) = u_C(0-)`

**原理**：电感电压 `u_L = L * di_L/dt`，若 `i_L` 突变则 `u_L → ∞`，不合理；电容同理（`i_C = C * du_C/dt`）。

**注意**：只有 `i_L` 和 `u_C` 不能突变，其余量（电阻电压、电容电流、电感电压等）在换路瞬间都可以突变。

## 二、求 t=0+ 时刻各量

固定步骤：

1. **求 0- 时刻**（换路前，电路已达稳态）
   - 稳态时电感相当于**短路**（`u_L=0`），电容相当于**开路**（`i_C=0`）
   - 用这个等效电路求出 `i_L(0-)` 或 `u_C(0-)`

2. **换路瞬间**：`i_L(0+) = i_L(0-)`，`u_C(0+) = u_C(0-)`（数值不变，直接代入）

3. **求 0+ 时刻其他量**：画出 0+ 等效电路——
   - 电感 → 用一个**电流源**代替，大小为 `i_L(0+)`
   - 电容 → 用一个**电压源**代替，大小为 `u_C(0+)`
   - 然后当作纯电阻电路，用 KCL / KVL 求其余支路电流、电压

## 三、时间常数 τ

- RC 电路：`τ = R_eq * C`
- RL 电路：`τ = L / R_eq`

**R_eq 求法**：把电感/电容所在支路断开，从这两个端子往回看，**独立源置零**（电压源短路、电流源开路），求剩余电阻网络的等效电阻（戴维南电阻）。

不同开关位置会对应不同的网络结构，需要分别置零电源、求等效电阻。

## 四、三要素法（求全响应，最重要）

只要是一阶电路（一个储能元件），任何变量 `f(t)`（电压或电流）的全响应都可以写成：

```
f(t) = f(∞) + [f(0+) - f(∞)] * e^(-t/τ)
```

三要素：

1. **f(0+)**：初始值，按第二部分方法求
2. **f(∞)**：新稳态值，把电感当短路、电容当开路，求换路后电路的稳态值
3. **τ**：时间常数，按第三部分方法求（用换路后的电路求 R_eq）

这一个公式统一了零输入响应、零状态响应、全响应，不需要分开算再叠加（叠加法也对，但三要素法更快）。

## 五、解题顺序总结

1. 判断换路前后电路结构
2. 求 0- 稳态 → 得到 `i_L(0-)` 或 `u_C(0-)`
3. 换路定则 → 得到 `i_L(0+)` 或 `u_C(0+)`
4. 若只要初始值：画 0+ 等效电路求其余量（用电流源/电压源替代储能元件）
5. 若要全响应：再求 `f(∞)`（新稳态）和 `τ`（新电路的 R_eq），代入三要素公式

## 示例：求 i_L(0+)

电路：10V 电源，左侧 100Ω 电阻，右侧并联 100Ω 电阻和 0.2H 电感，开关 S 在电感支路，t=0 时闭合（闭合前 S 断开）。

- **0- 时刻**：S 断开，电流只能走 100Ω(左) + 100Ω(右) 串联回路，电感相当于短路：
  `i_L(0-) = 10 / (100+100) = 0.05 A`
- **换路定则**：`i_L(0+) = i_L(0-) = 0.05 A = 50 mA`

（S 闭合后电路结构改变，`i_L` 会按新电路的时间常数从 0.05A 变化到新的稳态值，但 `i_L(0+)` 本身由换路前的值决定，不受换路瞬间新电路的影响。）
